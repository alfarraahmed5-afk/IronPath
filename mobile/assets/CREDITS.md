Acknowledgements for third-party assets bundled in the IronPath mobile
app. The in-app About screen sources strings from this file.

## Photography

Photos are bundled via the EAS build (per Lens 6 budget). Each photo
is documented in `mobile/assets/photos/MANIFEST.md` with file path,
source URL, license, and per-screen usage.

The current bundle plan uses photos under the **Unsplash License**
unless a row in MANIFEST.md is explicitly tagged `Custom-Stock` or
`Founder-Owned`.

## Open-source libraries

The full list of open-source libraries is in `mobile/package.json`.

submit.
