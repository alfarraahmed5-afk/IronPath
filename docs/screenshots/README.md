# Mobile App Design Reference Screenshots

Reference material for the IronPath mobile app's design and interface. Includes screenshots of IronPath itself plus the Hevy reference app for comparison/inspiration. Moved from `Screenshots-claude/` at the repo root on 2026-05-09 as part of the post-Phase-B repo cleanup.

## Layout

| Path | Contents |
|---|---|
| `IronPath/` | IronPath v1 app screenshots (2026-04-26) |
| `Others/` | Hevy reference screenshots (2026-04-26) |
| `V2/IronPath/` | IronPath v2 iteration screenshots (2026-04-27) |
| `V2/Others/` | Hevy reference screenshots, v2 iteration (2026-04-27) |

## When to use

- Reviewing past mobile UI decisions before changing a screen
- Comparing a proposed design against the Hevy reference (the closest-fit competitor)
- Onboarding new contributors to the visual language

If you add new screenshots, follow the existing naming convention `Screenshot_YYYYMMDD_HHMMSS_<App>.webp` and group under the appropriate iteration folder.
